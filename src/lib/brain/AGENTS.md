# Brain and Infinity guidance

- Infinity never posts canned template filler; when learning yields nothing it stays silent — random stock phrases misrepresent what it has learned.
- Infinity memory is passive ingestion of text already on the device (idle-time batched, capped, private posts skipped) and never initiates mesh requests, so it cannot compete with user connections.
- Infinity learns from memory in small idle-time batches and marks pieces learned; text already fed live is stored pre-marked, so nothing is learned twice.
- Brain chat, comments and replies use EntityVoice.generateText → DualLearningFusion as the single personality-guided realization path; stage stays observable, because duplicate samplers create conflicting voices.
- Realization preserves whole local learned expressions and rejects copied prompt openings before UQRC ranks candidates; curvature is not a semantic validator and unsupported output stays silent.
- Whole expressions remain in capped on-device storage separate from peer digests; restore historical learned memory without replaying ingestion, because vocabulary-only sync cannot preserve formula structure.
- Replace the shipped personality prior by its complete expression inventory, preserving memory expressions; seed via Dual ingestion on first realization so both learners share one prior.
- Phase 1 semantic basins (`src/lib/uqrc/semanticBasins.ts`) are device-local word geometry owned by LanguageLearner and never enter the mesh digest; tension needs ≥2 real co-occurrences, and the basin bridge in rankExpressions runs only when no expression shares a prompt topic, so exact matches and silence-on-no-support are unchanged.
- Phase 2 motifs (`src/lib/brain/semanticMotifs.ts`) cut only non-symbolic learned sentences into attunement/core/anchor clauses and join clauses from ≥2 different sentences only where Phase 1 tension between distinct words resonates (≥0.2) and no content word repeats; 'create'/'explore' intents prefer an assembled sentence whose core names a prompt topic, other intents keep whole expressions, and no resonant join means silence.
- Phase 3 arc (`src/lib/brain/discursiveArc.ts`) answers in Echo → Traverse → Crystallize paragraphs only when manifold mass ≥ ARC_MIN_MASS and at least two acts hold phase continuity ΔΦ ≥ 0.2; a shear or unsupported act halts the arc, a lone echo falls back to the single-sentence path, and no sentence repeats within an arc. Infinity's own posts/comments (`network-entity`) are excluded from memory backfill so generated text is never re-learned.
- Phase 4 engraved reflections: a complete Echo → Traverse → Crystallize arc (≥3 paragraphs, every boundary ΔΦ ≥ 0.3, calm field curvature) is engraved whole inside a hollow community-pool coin via `src/lib/blockchain/infinity/reflectionCoins.ts` (coin moves pool → `infinity`, sealed through applySeal, coin_transfer recorded, pool surplus wrapper kept, idempotent per seal). `src/lib/brain/coreMemories.ts` is only the brain's index: reflections wait there as pending until a coin holds them, coins are canonical on reload, and only coin-engraved sentences become touchstones, ordered first within an already-eligible relevance band, then lines from high-traffic peers (`routingFromNeurons`); neither ordering makes an ineligible line eligible.
- Infinity profile conversation is explicit opt-in, ephemeral and excluded from learning/digests; show device-local knowledge separately from live peer availability because digest exchange is not full memory replication.
- Brain room membership is app-level (brainSyncStore + BrainSyncHost); leaving the Brain page keeps the call and only explicit Disconnect or a live-room takeover ends it. A refresh is a disconnect (pagehide leave + silence sweep with departed tombstones), never a resume — prevents ghost peers.
- Earth land is three continent caps with noise-wobbled coasts in `src/lib/brain/surfaceProfile.ts` (`CONTINENTS`, `continentField`); EarthBody injects the generated `CONTINENTS_GLSL`, so never hand-edit continent noise in a shader. Keep radius + 2·COAST_WARP + MIN_OCEAN_GAP_RAD below every pair's separation, so the ocean always parts the continents. `snapToLand` falls back to the nearest continent unless the caller passes `fallback: 'seed'`.
- Brain peer mute is a local-only presentation filter in `src/lib/brain/mutedPeersStore.ts` (hides audio, video, avatar, placements, chat on this device); Block is the network-level P2P blocklist and also writes a mute entry, so every render filter consults only the mute store. Mute entries match by peerId OR userId because layers key the same person differently.
- Earth terrain is baked once per mesh vertex in `src/lib/brain/terrainMesh.ts`; the Earth mesh draws those triangles and every ground query (physics floor, avatar feet, camera guard, spawn lift) goes through `groundElevationAt`/`feetRadiusAt`, never a separate noise sample or a GPU re-derivation, because two terrains made players sink into drawn hills. The sea has a solid floor (beach → shelf → slope → 30 m ocean bed, `seaDepthFromContinents`); in water deeper than `SWIM_FEET_DEPTH` walkers swim at the surface (`supportElevationAt`), never sink below it. Islands (e.g. the shared village's, registered in `earth.ts` via `setIslandProvider`) raise the continents field; site snapping (`snapToLand`) reads the base noise land only, so adding an island never moves the village, the volcano or other snapped sites.
- Sky and weather run on shared game time in `src/lib/brain/earth.ts` (7 in-game days per real day); the Sun, Earth and Moon orbit the galactic core together and every live position comes from `EarthPose.sun`/`.moon` on the UTC epoch clock, never local elapsed time, so peers share one sky. Weather rates are per in-game hour (`WEATHER_TICK_GAME_HOURS`).
