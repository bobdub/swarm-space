# Brain and Infinity guidance

- Infinity never posts canned template filler; when learning yields nothing it stays silent — random stock phrases misrepresent what it has learned.
- Infinity memory is passive ingestion of text already on the device (idle-time batched, capped, private posts skipped) and never initiates mesh requests, so it cannot compete with user connections.
- Infinity learns from memory in small idle-time batches and marks pieces learned; text already fed live is stored pre-marked, so nothing is learned twice.
- Brain chat, comments and replies use EntityVoice.generateText → DualLearningFusion as the single personality-guided realization path; stage stays observable, because duplicate samplers create conflicting voices.
- Realization preserves whole local learned expressions and rejects copied prompt openings before UQRC ranks candidates; curvature is not a semantic validator and unsupported output stays silent.
- Whole expressions remain in capped on-device storage separate from peer digests; restore historical learned memory without replaying ingestion, because vocabulary-only sync cannot preserve formula structure.
- Replace the shipped personality prior by its complete expression inventory, preserving memory expressions; seed via Dual ingestion on first realization so both learners share one prior.
- Phase 1 semantic basins (`src/lib/uqrc/semanticBasins.ts`) are device-local word geometry owned by LanguageLearner and never enter the mesh digest; tension needs ≥2 real co-occurrences, and the basin bridge in rankExpressions runs only when no expression shares a prompt topic, so exact matches and silence-on-no-support are unchanged.
- Phase 2 motifs (`src/lib/brain/semanticMotifs.ts`) cut only non-symbolic learned sentences into attunement/core/anchor clauses and join clauses from ≥2 different sentences only where Phase 1 tension between distinct words resonates (≥0.2) and no content word repeats; 'create'/'explore' intents prefer an assembled sentence whose core names a prompt topic, other intents keep whole expressions, and no resonant join means silence.
- Phase 3 arc (`src/lib/brain/discursiveArc.ts`) answers in Echo → Traverse → Crystallize paragraphs only when manifold mass ≥ ARC_MIN_MASS and at least two acts hold phase continuity ΔΦ ≥ 0.2; a shear or unsupported act halts the arc, a lone echo falls back to the single-sentence path, and no sentence repeats within an arc. Infinity's own posts/comments (`network-entity`) are excluded from memory backfill so generated text is never re-learned.
- Phase 4 engraved reflections: a complete Echo → Traverse → Crystallize arc (≥3 paragraphs, every boundary ΔΦ ≥ 0.3, calm field curvature) is engraved whole inside a hollow community-pool coin via `src/lib/blockchain/infinity/reflectionCoins.ts` (coin moves pool → `infinity`, sealed through applySeal, coin_transfer recorded, pool surplus wrapper kept, idempotent per seal). `src/lib/brain/coreMemories.ts` is only the brain's index: reflections wait there as pending until a coin holds them, coins are canonical on reload, and only coin-engraved sentences become touchstones, ordered first within an already-eligible relevance band, then lines from high-traffic peers (`routingFromNeurons`); neither ordering makes an ineligible line eligible.
- Infinity profile conversation is explicit opt-in, ephemeral and excluded from learning/digests; show device-local knowledge separately from live peer availability because digest exchange is not full memory replication.
- Brain room membership is app-level (brainSyncStore + BrainSyncHost); leaving the Brain page keeps the call and only explicit Disconnect or a live-room takeover ends it. A refresh is a disconnect (pagehide leave + silence sweep with departed tombstones), never a resume — prevents ghost peers.
- Earth land is three continent caps with noise-wobbled coasts in `src/lib/brain/surfaceProfile.ts` (`CONTINENTS`, `continentField`); EarthBody injects the generated `CONTINENTS_GLSL`, so never hand-edit continent noise in a shader. Keep radius + 2·COAST_WARP + MIN_OCEAN_GAP_RAD below every pair's separation, so the ocean always parts the continents. `snapToLand` falls back to the nearest continent unless the caller passes `fallback: 'seed'`.
- Brain peer mute is a local-only presentation filter in `src/lib/brain/mutedPeersStore.ts` (hides audio, video, avatar, placements, chat on this device); Block is the network-level P2P blocklist and also writes a mute entry, so every render filter consults only the mute store. Mute entries match by peerId OR userId because layers key the same person differently.
- Earth terrain is baked once per mesh vertex in `src/lib/brain/terrainMesh.ts`; the Earth mesh draws those triangles and every ground query (physics floor, avatar feet, camera guard, spawn lift) goes through `groundElevationAt`/`feetRadiusAt`, never a separate noise sample or a GPU re-derivation, because two terrains made players sink into drawn hills. The sea has a solid floor (beach → shelf → slope → 30 m ocean bed, `seaDepthFromContinents`); in water deeper than `SWIM_FEET_DEPTH` walkers swim at the surface (`supportElevationAt`), never sink below it. Islands (e.g. the shared village's, registered in `earth.ts` via `setIslandProvider`) raise the continents field; site snapping (`snapToLand`) reads the base noise land only, so adding an island never moves the village, the volcano or other snapped sites.
- Sky and weather run on shared game time in `src/lib/brain/earth.ts` (7 in-game days per real day); the Sun, Earth and Moon orbit the galactic core together and every live position comes from `EarthPose.sun`/`.moon` on the UTC epoch clock, never local elapsed time, so peers share one sky. The Sun sits at a fixed ~23° declination (`SUN_DECLINATION`) so mid latitudes, the village included, get days and nights; site frames are laid out against the frozen `SITE_FRAME_SUN_POSITION`, so changing the Sun never moves the village, volcano or any anchor. Weather rates are per in-game hour (`WEATHER_TICK_GAME_HOURS`).
- Main Brain activity gate (`src/lib/world/placementActivity.ts`): a `global` placement with no activity for 5 days (newest of createdAt, author `activityAt` from place/move/edit/decorate/Refresh, decoration time, any wall view/reinforce/graffiti; future stamps ignored) goes idle. Peers drop it from records, IndexedDB, render and lobby snapshots without a tombstone, refuse idle copies, and an author Refresh brings it back through normal gossip. Own placements never go idle on the author's device. Separate from the 15-day author fadeout; project hubs and live rooms are never gated.
- Builder render mode (`src/lib/brain/builderRenderModeStore.ts`, Options → Performance): Light bypasses every user placement (UserPlacementsLayer renders nothing and `worldPlacementsStore` removes their engine blocks, so no colliders); Stacked is the default. `isPlacementSuppressed` is the single check for Light mode and Stop Support walls.
- Boats (`src/lib/brain/sea/`, overview in `docs/features/boats.md`) take their wind only from `windAt` (the field the clouds ride) and their swell, tilt and dead reckoning from the shared Earth clock. They step in `fleet.tick` after each physics tick and carry riders kinematically (sideways and with the deck's heave). A boat takes `PARTY_SIZE` (10) people, and a full boat's gates shut to newcomers. Food spends and fishing catches are device-local and never sent; presence `boat` is validated only by `decodeBoatPresence`.
- Boat readings render through ShipControls' portal into the shared Brain status target, keeping live samples out of the Canvas owner; station controls share the right-hand wheel/actions/compass/release column.
- Shy Node (`src/lib/p2p/shyMode.ts`, default not shy) is the learning switch: authors stamp `infinityLearn: true` on posts, comments and chat lines only while not shy (`agent/learnConsent.ts`), and every device learns, remembers or links only stamped items; unstamped content (shy authors, older clients) is never learned. Infinity's own lines are never stamped.
- Infinity's agent loop (`src/lib/brain/agent/infinityAgent.ts`) is the single idle-time scheduler for autonomous work, gated by one `ConnectionClock` (2 min drop grace): seamless memory → synapse linking always; 15 min+ one unprompted line in the shared chat (lowest peer id among recent speakers speaks, 30 min room cooldown, never shy, chat mode on, silence on empty realization, no 6-word quotes); 30 min+ reflection over its own lines and engraved coins; 2 h+ deep mapping. The synapse graph is device-local, bounded and never enters the mesh digest. The agent never moves community pool funds.
- Fire pits (`src/lib/world/fireStore.ts`, overview in `docs/features/fire-pits.md`): the `fire_pit_stone` prefab is built from the Tools tab and is never holdable. A fire is a pure fold of shared fuel facts over the clock (`burnUntil`), never a lit/out flag, so peers agree and fires go out with nothing sent; Wood is spent locally before a fact is recorded.
- Sea surface (`src/lib/brain/sea/seaSurface.ts`): the tide is the Moon's and Sun's equilibrium quadrupole on the shared Earth clock, and it is physical: the water shader (`components/brain/sea/seaMaterial.ts`), swimmers (`supportElevationAt`/`isSwimmingAt`) and boats (`Vessel.waterlineAt`) all read `tideAt`, so heads, hulls and water never part. Swell on the water is visual normal tilt only (the sea sphere's vertices are ~40 m apart); its trains share the boats' heave frequencies. Land claims and site snapping keep mean sea level, so the tide never moves ownership or sites.
- Volcano magma (`src/lib/brain/magmaConduit.ts`, `eruptionCycle.ts`, `lavaFlows.ts`, drawn by `VolcanoLavaPool`): the column rests `REST_DEPTH_M` down the conduit and rises with an overpressure that recharges on the shared clock; each `ERUPTION_CYCLE_S` cycle (onset and intensity from an integer hash of the cycle index, scaled by `ventSupplyPressure`, the mantle loop's steady state) ponds magma on the summit and sends tongues down the steepest descent of the baked ground, which then cool and weather away. The crater is smaller than one Earth mesh cell, so pond, vent window and flows are draped on `sampleTerrainLift`, never flat plates. The conduit is seen only through the stencil vent window, never by cutting the baked crater. The plume colours each parcel by `ventEmissionAt` at its birth: faint white fumarole steam when quiet, dark ash only while erupting or on slug bursts near the surface. Mantle pressure (`getMantlePressure(t)`) is a pure read of the shared Earth clock, never integrated per device from `Date.now()`: the steady state swung by the eruption cycle, so the vent sink, glow and emissions agree on every peer.
- NPC heartbeat and reproduction ticks sleep unless a Brain scene holds `retainNpcScene()` (`src/lib/brain/npc/npcSceneGate.ts`), the tab is visible and the camera is within 300 m of the village (sleeps again past 360 m). Position-only `upgradeBlock` moves go through `moveSupportBasin` (re-stamp only on a lattice-cell change); the Brain field snapshot saves every 2.5 min and on unmount or tab hide, never on a seconds timer.
- Dropped tools and NPCs (`src/lib/world/droppedToolsStore.ts`, `src/lib/brain/npc/npcTools.ts`): a holdable tool placement on the ground (not the Boundary Marker or fire pit) is collected by a village NPC that owns no tool of that kind, within 80 m of the village. Each tool ends with one shared fact per placement, `pickup` (NPC name, the cross-device identity) or `vanish` (stamped drop + 60 s, recorded only when every NPC on the roster owns that kind); every peer keeps the earliest (pickup beats vanish on a tie, then NPC name, then recorder), and applying it retires the placement through a normal tombstone (`retirePlacement`), so it leaves view, storage and backfill. NPC tool ownership is a fold of winning pickups; tools raise only the NPC's own yield in `wetWork`, never the labour weight.
- Render governor (`src/lib/brain/renderGovernor.ts`, hook `components/brain/useGovernedFrame.ts`): per-frame work opts into a tier (critical, proximity, ambiance) and receives accumulated delta, because skipped frames must not slow time-driven motion; the governor only learns from local frame time and never touches shared-clock state. Pacing is currently off (`TIER_INTERVAL_S` all zero): the Brain is GPU-bound (main-thread JS under 5% of frame time), so skipping JS frames only made motion choppy. Sustained `strained` pressure instead latches the Canvas resolution to 1× for the session (`useAdaptiveDpr`, passed as the Canvas `dpr` prop, which the Canvas re-applies on every render). Sea life and hens run on proximity (Earth transform stays every frame), remote avatars beyond 40 m on ambiance. Nests cap eggs and chicks per flock in layAt order and lattice sea homes keep a minimum spacing, so all peers agree and life never overflows.
- Constellations (`src/lib/brain/constellations.ts`, drawn by `components/brain/Constellations.tsx`, overview in `docs/features/constellations.md`): the Cat, Dragon, Pirate Ship and Flask are fixed world directions baked once into two draw calls; Earth turns under them on the shared pose clock and they fade with `skyCadenceAt().starOpacity`, so never animate them from local time or per-frame JS loops.
